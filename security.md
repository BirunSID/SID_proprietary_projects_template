# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please do **NOT** open a public issue.

Instead, please report it privately via GitHub:
1. Navigate to the **Security** tab of this repository.
2. Click **Report a vulnerability** to open a private draft advisory.

### Response Timeline
- **Initial acknowledgment:** Within 48 hours.
- **Status update:** Within 7 business days with an assessment or patch plan.
- **Coordination:** Public release details will be coordinated before advisory publication.
